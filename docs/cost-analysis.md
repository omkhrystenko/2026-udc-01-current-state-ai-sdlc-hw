# Cost analysis — Task 3

## Метод вимірювання
- Розмір контексту поміряно через `npx repomix` (кодування `o200k_base`).
- Споживання токенів сесії додатково видно в Claude Code командою `/cost`.
- Вартість порахована за офіційними цінами Claude API (за 1 млн токенів):

| Модель | Input $/1M | Output $/1M |
|---|---|---|
| Opus 4.8 | $5 | $25 |
| Sonnet 4.6 | $3 | $15 |
| Haiku 4.5 | $1 | $5 |

## Реальні виміри (repomix)

| Що міряли | Файли | Токени |
|---|---|---|
| Увесь репозиторій (зі скілом) | 103 | **70 078** |
| Без теки скіла `.agents/` | 27 | **11 186** |
| Один файл скіла `vercel-react-best-practices/AGENTS.md` | 1 | **26 362** (37.6% усього) |

→ Встановлений Agent Skill додає ~59 000 токенів — це **84%** усього контексту.

## Орієнтовна вартість одного запиту до фічі

Припущення: агент зчитує контекст (input) + генерує ~2 000 токенів коду (output).

### З повним контекстом (70 078 input + 2 000 output)
| Модель | Розрахунок | Вартість |
|---|---|---|
| Opus 4.8 | 70 078×$5 + 2 000×$25 /1M | **$0.40** |
| Sonnet 4.6 | 70 078×$3 + 2 000×$15 /1M | **$0.24** |
| Haiku 4.5 | 70 078×$1 + 2 000×$5 /1M | **$0.08** |

### З вузьким контекстом, без скіла (11 186 input + 2 000 output)
| Модель | Розрахунок | Вартість |
|---|---|---|
| Opus 4.8 | 11 186×$5 + 2 000×$25 /1M | **$0.11** |
| Sonnet 4.6 | 11 186×$3 + 2 000×$15 /1M | **$0.06** |
| Haiku 4.5 | 11 186×$1 + 2 000×$5 /1M | **$0.02** |

## Оптимізації (2-3)
1. **Вузький контекст.** Виключення теки скіла зі скоупу зменшує контекст з 70k
   до 11k токенів (−84%) → вартість запиту на Opus падає з $0.40 до $0.11 (−72%).
2. **Дешевша модель для рутини.** Прості фічі (лічильник, форма) на Haiku 4.5
   замість Opus 4.8 дешевші у ~5 разів ($0.08 vs $0.40 за повного контексту).
3. **Prompt caching + чіткі промпти.** Повторне читання контексту з кешу коштує
   ≈0.1× від input; чіткий промпт із самого початку зменшує кількість ітерацій
   (а отже й повторних оплат контексту).

## Висновки
1. Найбільший пожирач токенів — не код проєкту (11k), а **один файл скіла**
   (26k, 37.6%). Контекст AI треба тримати вузьким: великі довідкові файли
   варто підвантажувати лише за потреби, а не тримати в кожному запиті.
2. Вибір моделі під задачу дає економію в рази: рутину робити на Haiku/Sonnet,
   Opus лишати для складних задач. Поєднання «вузький контекст + дешевша модель»
   здешевлює простий запит з $0.40 до $0.02 (×20).
