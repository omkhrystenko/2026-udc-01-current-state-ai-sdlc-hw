## Task 2 — фіча «Лічильник» через режими Plan → Agent

### Acceptance criteria (визначені ДО коду)
1. На сторінці видно число, початкове значення — 0.
2. Кнопка «+1» збільшує число на 1.
3. Кнопка «−1» зменшує число на 1.
4. Кнопка «Скинути» повертає число до 0.
5. Число не стає від'ємним (на 0 кнопка «−1» неактивна).

### Режим Plan
Попросив агента скласти план *без* написання коду. Узгоджений план:
- створити клієнтський компонент `app/app/components/Counter.tsx`
  (`"use client"`, `useState(0)`, кнопки +1/−1/Скинути, `−1` `disabled` на 0,
  стилі лише Tailwind, тексти українською);
- замінити заглушку в `app/app/page.tsx` на `<Counter />` по центру;
- перевірка через `npm run dev`.

**Що скоригував після рев'ю плану:** додав вимогу блокувати «−1» на нулі
(захист від від'ємних значень) — у початковому формулюванні цього не було.

### Режим Agent
Агент реалізував за погодженим планом:
- ➕ `app/app/components/Counter.tsx`
- ✏️ `app/app/page.tsx`

### Рев'ю та перевірка
- `npm run lint` — без помилок.
- Ручна перевірка в браузері (`http://localhost:3000`): усі 5 acceptance
  criteria виконуються.

### Висновок
Plan-режим дав змогу зловити прогалину (від'ємні числа) ще до коду; Agent-режим
реалізував усе з першого проходу без правок.
